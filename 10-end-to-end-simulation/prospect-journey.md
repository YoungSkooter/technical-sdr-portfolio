## Stage-by-Stage Journey

| Stage | SDR Objective | Evidence | Action | Output |
|---|---|---|---|---|
| Target | Identify potential fit | Public signals | Research | Account profile |
| Persona | Find relevant stakeholder | Role/function | Map buying group | Persona map |
| Hypothesis | Identify possible problem | Technical signals | Form hypothesis | Problem hypothesis |
| Outreach | Test hypothesis | Research | Send targeted message | Prospect response |
| Qualification | Determine whether problem matters | Simulated response | Ask qualification questions | Qualification record |
| Discovery | Understand workflow | Simulated conversation | Map technical process | Discovery notes |
| Handoff | Transfer context | Discovery evidence | Brief AE/SE | Handoff docs |
| Product | Understand solution | Product research | Map capabilities/use cases | Product teardown |
| CRM | Track opportunity | Sales data | Update record | Pipeline record |
| Analysis | Improve outbound | Simulated dataset | Analyze funnel | Optimization plan |
| Validation | Test technical fit | Technical requirements | Coordinate SE | Technical evaluation |
