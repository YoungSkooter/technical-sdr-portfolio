# Sequence Optimization Plan

> **SIMULATION**

---

# Current Hypothesis

The messaging appears most relevant when targeting technical personas close to:

- Security investigation
- Cloud security
- Security automation
- Remediation workflows

---

# Experiment 1 — Persona

### Hypothesis

Security Engineering and Cloud Security may produce stronger qualified conversations than broader technical personas.

### Test

Create separate sequences for:

**A — Security Engineering**

Focus:

- Investigation
- Context
- Automation

**B — Cloud Security**

Focus:

- Risk
- Cloud context
- Prioritization

### Success Metric

**Qualified opportunities / accounts targeted**

Not simply replies.

---

# Experiment 2 — Message

### Version A

Problem-first:

> "Where does your team still manually gather context during complex cloud-security investigations?"

### Version B

Outcome-first:

> "How much investigation time does your team spend gathering context before deciding which cloud findings require action?"

### Measure

- Reply rate
- Positive reply rate
- Meetings
- Qualified opportunities

---

# Experiment 3 — CTA

### Version A

Question:

> "Curious how you handle this today?"

### Version B

Conversation:

> "Worth comparing how other cloud-security teams handle this?"

### Version C

Meeting:

> "Open to a 20-minute discussion?"

The goal is to determine whether lower-friction CTAs produce more meaningful conversations.

---

# Experiment 4 — Sequence Length

Compare:

### Sequence A

3 touches

### Sequence B

5 touches

Measure:

- Incremental replies
- Positive replies
- Meetings
- Qualified opportunities

The goal is to determine whether additional touches create meaningful pipeline rather than simply additional activity.

---

# Experiment 5 — Trigger-Based Personalization

Compare generic ICP messaging against messaging triggered by:

- Kubernetes adoption
- Cloud expansion
- Security engineering hiring
- Security automation initiatives
- New compliance requirements
- Infrastructure changes
- Security incidents/public disclosures

The hypothesis:

> Specific technical triggers may create more relevant conversations than generic industry personalization.
