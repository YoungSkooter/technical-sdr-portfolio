# Outreach Strategy — Figma

> **Simulation:** This is a simulated outbound exercise. No messages
> have been sent to Figma or its employees.

## Objective

The objective of the initial outbound campaign is not to sell a product.

It is to determine whether the technical workflow identified during
account research represents a meaningful problem.

## Research-Based Trigger

Figma has publicly described:

- AWS infrastructure
- Kubernetes
- Security Engineering
- Panther-based security monitoring
- Security data lake architecture
- Security alert investigation
- Security automation
- Automated remediation

The strongest outbound signal is Figma's public discussion of
automating security alert investigation and reducing investigation
time.

## Core Hypothesis

Figma has already invested substantially in security automation.

The outbound question is therefore not:

> "Do you have security automation?"

Instead:

> "Where does manual investigation still exist despite the automation
> already in place?"

## Primary Persona

Security Engineering

## Secondary Personas

- Cloud Security
- Platform Security
- Security Operations
- Platform Engineering
